# 5장. 실시간 집계

## 이 장은 어디서 시작하나?

2장의 집계는 다음 날 아침에 나옵니다. 정산 담당자는 지금 판매자별 매출과 취소를 보고 싶어 합니다. 4장에서 다진 토픽 위에 Flink로 실시간 집계를 만듭니다. 늦게 오는 이벤트, 장애 복구, 작업 변경 배포가 차례로 문제가 됩니다.

환경: `docker compose --profile cdc --profile stream up -d --wait`. Flink 2.1(`http://127.0.0.1:8081`), Kafka 커넥터 4.0.1-2.0, Iceberg 런타임 1.10. SQL 작업은 `flink/sql/`에 두고 `docker compose exec jobmanager /opt/flink/bin/sql-client.sh -f /opt/sql/<파일>`로 돌립니다. 체크포인트와 savepoint는 `flinkdata` 볼륨에 쌓입니다.

## 무엇을 공부하나?

- 이벤트 시간과 처리 시간, watermark, 허용 지연 (블로그 16편)
- 윈도와 join (블로그 17편)
- 체크포인트, 장애 복구, 백프레셔 (블로그 18편)
- 전달 보장과 exactly-once, Kafka 트랜잭션, `read_committed` (블로그 14편)
- savepoint, 연산자 uid, 상태 스키마 변경
- Debezium 레코드를 Flink에서 읽는 방법(`debezium-json` 형식, 변경 로그 스트림)

## 실험

### E5-1. 늦게 확정되는 결제는 몇 건이나 윈도를 놓칠까?

- 질문: `UNKNOWN`에서 몇 초~몇 분 뒤 `DONE`이 되는 결제를 승인 시각 기준 1분 윈도로 집계하면, 허용 지연에 따라 몇 건이 빠질까?
- 바꿀 조건: watermark 지연 0초, 10초, 60초.
- 볼 것: 윈도별 누락 건수와 금액(정답은 2장 배치 결과), 결과가 나오기까지의 지연.
- 근거 등급: `E2`.

### E5-2. 따라잡는 동안 처리 시간 윈도는 무엇을 낼까?

- 질문: 4장 E4-9처럼 밀린 데이터를 따라잡는 동안 처리 시간 윈도와 이벤트 시간 윈도의 결과는 얼마나 다를까?
- 볼 것: 같은 구간의 두 결과와 정답의 차이.
- 근거 등급: `E2`.

### E5-3. 체크포인트 간격은 복구에 어떤 값을 치를까?

- 질문: 체크포인트 10초와 60초에서 TaskManager를 죽이면 다시 처리하는 레코드 수와 복구 시간은 얼마나 다를까? Kafka 싱크를 exactly-once로 두면 소비자 쪽 지연은 어떻게 될까?
- 볼 것: 재처리 건수, 복구 시간, `read_committed` 소비자가 결과를 보기까지의 지연.
- 근거 등급: `E2`.

### E5-4. uid 없이 쿼리를 바꾸면 savepoint에서 복원될까?

- 질문: 집계 쿼리에 컬럼 하나를 더하고 savepoint에서 다시 띄우면 상태를 이어받을까?
- 바꿀 조건: 연산자 uid 지정 여부, `allowNonRestoredState`.
- 볼 것: 복원 성공 여부와 오류, 복원 뒤 집계 값이 이어지는지(0부터 다시 세는지).
- 근거 등급: `E2` (Flink 문서의 uid 지정 권고).

### E5-5. 싱크가 느려지면 체크포인트는 어떻게 될까?

- 질문: 싱크에 인위적 지연을 넣으면 백프레셔가 체크포인트 소요 시간을 얼마나 늘릴까? unaligned checkpoint는 무엇을 바꿀까?
- 볼 것: 체크포인트 소요 시간, 정렬 대기 시간, 소스 lag.
- 근거 등급: `E2`.

### E5-6. 실시간 값과 아침 배치 값은 같을까?

- 질문: 같은 날의 실시간 집계 최종값과 2장 배치 확정치는 일치할까? 다르면 어느 쪽이 무엇을 놓쳤을까?
- 방법: 결제와 정산 항목을 `order_no`로 interval join하는 작업과, 판매자별 일 합계 작업을 함께 둡니다.
- 볼 것: 판매자별 차이와 원인 분류(늦은 데이터, 중복, 시간대).
- 7장 대조의 시작입니다.
- 근거 등급: `E2`.

## 이 장이 끝나면 남는 문제

토픽 보존은 24시간이고 원본은 현재 상태만 들고 있습니다. 지난달 취소 이력을 다시 계산하려면 이력을 싸게 오래 둘 곳이 필요합니다. 6장으로 갑니다.
